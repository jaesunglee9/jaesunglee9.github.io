Programmers 84512 — 모음사전

Source

https://school.programmers.co.kr/learn/courses/30/lessons/84512

Problem

사전에 알파벳 모음 'A', 'E', 'I', 'O', 'U'만을 사용하여 만들 수 있는, 길이 5 이하의 모든 단어가 수록되어 있습니다. 사전에서 첫 번째 단어는 "A"이고, 그다음은 "AA"이며, 마지막 단어는 "UUUUU"입니다.

단어 하나 word가 매개변수로 주어질 때, 이 단어가 사전에서 몇 번째 단어인지 return 하도록 solution 함수를 완성해주세요.

제한사항

  • word의 길이는 1 이상 5 이하입니다.
  • word는 알파벳 대문자 'A', 'E', 'I', 'O', 'U'로만 이루어져 있습니다.

Solution

#include <string>
#include <vector>

using namespace std;

string w;
int cnt;
char vowels[5] = {'A', 'E', 'I', 'O', 'U'};

void
dfs(string str, int& answer) {
    if (str.size() > 5) return;
    if (str == w) {
        answer = cnt;
        return;
    }

    cnt += 1;

    for (auto ch : vowels) {
        dfs(str + ch, answer);
    }
}

int solution(string word) {
    int answer = 0;
    w = word;
    dfs("", answer);
    return answer;
}

Approach

The solution treats every string of at most five vowels as a node in an implicit choice tree. It visits a prefix, then recursively appends A, E, I, O, and U in that order. This preorder Depth First Search visits the nonempty strings in the same order as the dictionary, so the visit counter at the target is its dictionary position. Recursion terminates beyond depth 5.

Implementation note

Found an improvement where I can exit early from dfs by checking if answer, which is supposed to be nonzero iff answer has been found. 

#include <string>
#include <vector>

using namespace std;

void dfs(string& current, const string& target, int& counter, int& answer) {
    if (current == target) {
        answer = counter;
        return;
    }
    if (current.size() == 5) {
        return;
    }

    const char vowels[] = {'A', 'E', 'I', 'O', 'U'};

    for (char ch : vowels) {
        current.push_back(ch);
        counter++;

        dfs(current, target, counter, answer);
        if (answer != 0) return; // Prune: stop searching once found

        current.pop_back(); // Backtrack
    }
}

int solution(string word) {
    int counter = 0;
    int answer = 0;
    string current = "";

    dfs(current, word, counter, answer);

    return answer;
}

This version uses Backtracking to reuse one mutable string. After returning from a child, it removes that child's vowel before exploring the next choice. Once the target is found, answer ! 0= stops each active caller from exploring more branches. Zero is available as the sentinel because dictionary positions begin at one.

Remarks

When a recursive search finds a definitive result, returning from the deepest call alone does not stop its callers. Propagate a success signal through every active call so that each level terminates its remaining search. An answer value can double as that signal only when the chosen sentinel cannot also be a valid answer.
