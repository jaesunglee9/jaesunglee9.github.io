Programmers 144856 — 저자 별 카테고리 별 매출액 집계하기

Problem

English summary of the linked problem: calculate January 2022 book revenue by author and category. Revenue is sales quantity multiplied by price. Return AUTHOR_ID, AUTHOR_NAME, CATEGORY, and TOTAL_SALES as shown in the expected output. Sort by author ID ascending, then category descending.

Schemas

All columns are non-null.

BOOK

Column Type Meaning
BOOKID INTEGER Book ID
CATEGORY VARCHAR(N) Category
AUTHORID INTEGER Author ID
PRICE INTEGER Price in won
PUBLISHEDDATE DATE Publication date

Categories: 경제, 인문, 소설, 생활, 기술.

Expected output

2 김영호 경제 18000

Solution

-- 코드를 입력하세요
SELECT 
        B.AUTHOR_ID,
    A.AUTHOR_NAME,
    B.CATEGORY,
    SUM(S.SALES_COUNT * B.PRICE) AS SALES
FROM
    BOOK B
JOIN
    AUTHOR A ON B.AUTHOR_ID = A.AUTHOR_ID
JOIN (
    SELECT 
        BOOK_ID, SUM(SALES) SALES_COUNT
    FROM 
        BOOK_SALES
    WHERE 
        SALES_DATE LIKE '2022-01%'
    GROUP BY 
        BOOK_ID    
) S ON B.BOOK_ID = S.BOOK_ID
GROUP BY
    B.AUTHOR_ID,
    A.AUTHOR_NAME,
    B.CATEGORY
ORDER BY
A.AUTHOR_ID ASC,
B.CATEGORY DESC

Approach

The subquery filters January sales and totals the quantity for each book. The outer query joins those quantities to book prices and author details, then totals revenue by author and category.

Remarks

Remember SQL LIKE patterns: % matches zero or more characters, while _ matches exactly one. The pattern '2022-01%' means “starts with 2022-01.” These are SQL wildcards, not regular-expression syntax.

Choose the wildcard position to express the match: 'place%' for a prefix, '%place' for a suffix, and '%place%' for a substring. When recalling the syntax, ask which part of the text is fixed and which part may vary.
