Programmers 299310 — 연도별 대장균 크기의 편차 구하기

Problem

English summary of the linked problem: for each bacterium in ECOLI_DATA, return its differentiation year as YEAR, the difference between that year's largest colony size and its own size as YEAR_DEV, and its ID. Sort by YEAR ascending, then YEAR_DEV ascending.

Schema

Column Type Nullable Meaning
ID INTEGER No Individual ID
PARENTID INTEGER Yes Parent ID
SIZEOFCOLONY INTEGER No Colony size
DIFFERENTIATIONDATE DATE No Differentiation date
GENOTYPE INTEGER No Genotype

Founding individuals have NULL parent IDs.

Example input

ECOLI_DATA:

ID PARENTID SIZEOFCOLONY DIFFERENTIATIONDATE GENOTYPE
1 NULL 10 2019/01/01 5
2 NULL 2 2019/01/01 3
3 1 100 2020/01/01 4
4 2 10 2020/01/01 4
5 2 17 2020/01/01 6
6 4 101 2021/01/01 22

Expected output

YEAR YEARDEV ID
2019 0 1
2019 8 2
2020 0 3
2020 83 5
2020 90 4
2021 0 6

Solution

SELECT YEAR(DIFFERENTIATION_DATE) AS YEAR,
    (MAX(SIZE_OF_COLONY) OVER (PARTITION BY YEAR(DIFFERENTIATION_DATE)) - SIZE_OF_COLONY) AS YEAR_DEV,
    ID
FROM ECOLI_DATA 
ORDER BY YEAR ASC, YEAR_DEV ASC

Approach

I didn't know the difference between GROUP BY and PARTITION BY, or what invoking MAX over such a partition meant.

Remarks

Use a window aggregate when each result row needs its own values alongside a statistic for its group. Here, every bacterium keeps its ID and size while receiving the maximum colony size for its year. The difference can then be calculated on each row.

GROUP BY instead produces one row per group. Selecting an ungrouped size is ambiguous when a year contains several sizes; an aggregate chooses a summary, while adding size to the grouping keys changes what constitutes a group.
