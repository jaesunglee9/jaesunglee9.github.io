Programmers 157340 — 자동차 대여 기록에서 대여중 / 대여 가능 여부 구분하기

Problem

English summary of the linked problem: using CAR_RENTAL_COMPANY_RENTAL_HISTORY, return each car's CAR_ID and its availability on 2022-10-16 as AVAILABILITY. Use 대여중 for cars rented on that date and 대여 가능 otherwise. A rental ending on 2022-10-16 still counts as rented. Sort by CAR_ID descending.

Schema

Column Type Nullable Meaning
HISTORYID INTEGER No Rental-history ID
CARID INTEGER No Car ID
STARTDATE DATE No Rental start date
ENDDATE DATE No Rental end date

Example input

CAR_RENTAL_COMPANY_RENTAL_HISTORY:

HISTORYID CARID STARTDATE ENDDATE
1 4 2022-09-27 2022-09-27
2 3 2022-10-03 2022-10-04
3 2 2022-10-05 2022-10-05
4 1 2022-10-11 2022-10-16
5 3 2022-10-13 2022-10-15
6 2 2022-10-15 2022-10-17

Expected output

CARID AVAILABILITY
4 대여 가능
3 대여 가능
2 대여중
1 대여중

Solution

SELECT CAR_ID,
    CASE
        WHEN MAX(CASE WHEN START_DATE <= '2022-10-16' AND '2022-10-16' <= END_DATE THEN 1 ELSE 0 END) = 1
        THEN '대여중'
        ELSE '대여 가능'
    END AVAILABILITY
FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
GROUP BY CAR_ID
ORDER BY CAR_ID DESC

Approach

Group by CAR_ID to consider all rental records for each car. Check whether 2022-10-16 falls between each record's start and end dates, including both endpoints. If any record matches, label the car 대여중; otherwise, label it 대여 가능.

The alternative below uses a subquery to find car IDs rented on that date, then uses IN to check whether each car belongs to that set. 

SELECT 
    CAR_ID,
    CASE 
        WHEN CAR_ID IN (
            SELECT CAR_ID
            FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
            WHERE '2022-10-16' BETWEEN START_DATE AND END_DATE
        ) THEN '대여중'
        ELSE '대여 가능'
    END AS AVAILABILITY
FROM 
    CAR_RENTAL_COMPANY_RENTAL_HISTORY
GROUP BY 
    CAR_ID
ORDER BY 
    CAR_ID DESC;

Remarks

The reusable idea is conditional aggregation: turn each row's condition into a 0/1 flag, then reduce the flags to one answer for the group. MAX returns 1 if any flag is 1. For car 2, the two records yield 0 and 1, so the group is marked as rented.

This is an OR across rows. Ordinary OR combines explicitly written expressions; an aggregate combines values from the group's rows. CASE WHEN condition THEN value ELSE other_value END supplies the flag or selects the final label.

PostgreSQL equivalent

PostgreSQL expresses the same group-level question directly with BOOL_OR. In this problem, both date columns are non-null, so the predicate produces true or false for every rental record. The outer CASE can use the Boolean aggregate directly: 

CASE
    WHEN BOOL_OR(DATE '2022-10-16' BETWEEN START_DATE AND END_DATE)
    THEN '대여중'
    ELSE '대여 가능'
END AS AVAILABILITY

This expression belongs in the same SELECT grouped by CAR_ID. MySQL does not provide BOOL_OR; the existing MAX(CASE ... THEN 1 ELSE 0 END) = 1 expresses the same question here. MySQL also permits MAX(condition) because comparisons produce 0/1 values.
