programmers-42861 — Connecting Islands (섬 연결하기)

Source

Programmers 42861 — 섬 연결하기 (C++)

Problem

This is an English summary of the original problem. See the source link for the full statement and illustration.

Given n islands and the available bridge-building costs, return the minimum total construction cost that lets someone travel between every pair of islands. A journey may cross multiple bridges.

Interface and constraints

  • Function: int solution(int n, vector<vector<int>> costs)
  • n is between 1 and 100, inclusive.
  • costs contains at most n * (n - 1) / 2 entries.
  • Each entry [a, b, cost] gives the two islands and their bridge's construction cost.
  • Connections are undirected, and no pair appears more than once, including reversed pairs.
  • A pair absent from costs cannot be connected directly by a bridge.
  • The available connections allow all islands to be connected.

Example

n costs return
4 [[0,1,1],[0,2,2],[1,2,5],[1,3,1],[2,3,8]] 4

Solution

#include <string>
#include <vector>
#include <numeric>
#include <algorithm>

using namespace std;

class Edge {
    public: 
    int u;
    int v;
    int w;

    Edge(int u, int v, int w) : u(u), v(v), w(w) {}

    bool operator < (const Edge& other) {
        return this->w < other.w;
    }
};

class DS {
    private:
    vector<int> parent;
    vector<int> rank;

    public:
    DS(int size) {
        parent.resize(size+1);
        rank.resize(size+1);
        iota(parent.begin(), parent.end(), 0);
        rank.assign(size+1, 0);
    }

    int find(int x) {
        if (parent[x] == x) return x;
        return parent[x] = find(parent[x]);
    }

    bool unite(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);

        if (rootX == rootY) return false;

        if (rank[rootX] < rank[rootY]) {
            parent[rootX] = rootY;
        }
        else if (rank[rootX] > rank[rootY]) {
            parent[rootY] = rootX;
        }
        else {
            parent[rootY] = rootX;
            rank[rootX] += 1;
        } 

        return true;
    }
};

int solution(int n, vector<vector<int>> costs) {
    int answer = 0;

    sort(costs.begin(), costs.end(), [](const vector<int>& a, const vector<int>& b) {
        return a[2] < b[2];
    });

    DS ds(n);
    int ec = 0;
    for (auto e : costs) {
        if (ds.unite(e[0], e[1]) == true) {
            answer += e[2];
            ec += 1;
        }

        if (ec == n - 1) break;
    }
    return answer;
}

Classification

This solution uses Kruskal's algorithm to build a minimum spanning tree by considering bridges in increasing cost order. Its Union-Find implementation uses path compression and union by rank to track the connected components.
