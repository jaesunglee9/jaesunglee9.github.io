Updating GNU Guix (Properly)

GNU Guix is an excellent operating system, but its substitutes are sometimes janky, and when they are, Guix daemon tries to compile them from scratch, which is impractical and sometimes impossible for end users. Nevertheless, doing the standard ```guix pull``` followed by reconfigures can sometimes fail, due to instability of substitutes farm. Your system might begin compiling a new definition for nearly a day, only to fail. The following will describe ways to use update guix only when substitutes farms are fully available.

Step 1. Pull

Run command ```guix pull```. This command updates local package definitions.

2. Dry Run

```guix system build </path/to/your/config.scm> –dry-run```

Then upgrade the rest.
