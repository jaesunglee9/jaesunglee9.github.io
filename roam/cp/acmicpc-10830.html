문제

크기가 N*N인 행렬 A가 주어진다. 이때, A의 B제곱을 구하는 프로그램을 작성하시오. 수가 매우 커질 수 있으니, AB의 각 원소를 1,000으로 나눈 나머지를 출력한다.

입력

첫째 줄에 행렬의 크기 N과 B가 주어진다. (2 ≤ N ≤ 5, 1 ≤ B ≤ 100,000,000,000)

둘째 줄부터 N개의 줄에 행렬의 각 원소가 주어진다. 행렬의 각 원소는 1,000보다 작거나 같은 자연수 또는 0이다.

출력

첫째 줄부터 N개의 줄에 걸쳐 행렬 A를 B제곱한 결과를 출력한다.

Remark

A variation of the well known exponentiation implementation. I wonder how modern optimized programs handle large expoenents. That said, the solution did not arrive without its quirks. In the ```matmul``` function, matmul expects references, which must be named, apparently. This was solvable by pulling out the intermediary value as 'half', which admittedly made the code better structured. Same issue arose for the 'reduce' function, but in this case the solution was a bit more cumbersome. Apparently I need to utilize move semantics(C++11) and change function signature of 'reduce' so that it can take unnamed variables. I still don't think I like it very much. Why try to be something you can't be? I mean, I would rather use rust. Nevertheless, after the fix, the code runs smoothly.

#include <iostream>
#include <vector>

using namespace std;
using ll = long long;

int n;
ll b;
vector<vector<int>> a;

void
print(const vector<vector<int>>& mat)
{
        for (int i = 0; i < n; i++)
        {
                for (int j = 0; j < n; j++)
                {
                        cout << mat[i][j] << ' ';
                }
                cout << '\n';
        }
        return;
}

void
reduce(vector<vector<int>>& mat)
{
        for (int i = 0; i < n; i++)
        {
                for (int j = 0; j < n; j++)
                {
                        mat[i][j] %= 1000;
                }
        }
        return;
}

vector<vector<int>>
reduce(vector<vector<int>>&& mat)
{
    reduce(mat); 
    return std::move(mat); 
}

vector<vector<int>>
matmul(const vector<vector<int>>& mat1, const vector<vector<int>>& mat2)
{
        vector<vector<int>> res(n, vector<int>(n, 0));

        for (int i = 0; i < n; i++)
        {
                for (int j = 0; j < n; j++)
                {
                        for (int k = 0; k < n; k++)
                        {
                                res[i][j] += (mat1[i][k] * mat2[k][j]);
                        }
                }
        }

        return res;
}    

vector<vector<int>>
exp(const vector<vector<int>>& mat, ll exponent)
{
        if (exponent == 1) return reduce(vector<vector<int>>(mat));

        vector<vector<int>> half = exp(mat, exponent / 2);
        if (exponent % 2 == 0)
        {
                return reduce(matmul(half, half));
        }
        else
        {
                return reduce(matmul(reduce(matmul(half, half)), mat));
        }
}

void
sol0(void)
{
        cin >> n >> b;
        a.resize(n, vector<int>(n));

        for (int i = 0; i < n; i++)
        {
                for (int j = 0; j < n; j++)
                {
                        cin >> a[i][j];
                }
        }

        vector<vector<int>> c = exp(a, b);

        print(c);

        return;
}


int
main(void)
{
        ios::sync_with_stdio(0); cin.tie(0);
        sol0();
        return 0;
}
