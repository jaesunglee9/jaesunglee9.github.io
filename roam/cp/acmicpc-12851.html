acmicpc-12851

Problem

수빈이는 동생과 숨바꼭질을 하고 있다. 수빈이는 현재 점 N(0 ≤ N ≤ 100,000)에 있고, 동생은 점 K(0 ≤ K ≤ 100,000)에 있다. 수빈이는 걷거나 순간이동을 할 수 있다. 만약, 수빈이의 위치가 X일 때 걷는다면 1초 후에 X-1 또는 X+1로 이동하게 된다. 순간이동을 하는 경우에는 1초 후에 2*X의 위치로 이동하게 된다.

수빈이와 동생의 위치가 주어졌을 때, 수빈이가 동생을 찾을 수 있는 가장 빠른 시간이 몇 초 후인지 그리고, 가장 빠른 시간으로 찾는 방법이 몇 가지 인지 구하는 프로그램을 작성하시오.

입력

첫 번째 줄에 수빈이가 있는 위치 N과 동생이 있는 위치 K가 주어진다. N과 K는 정수이다.

출력

첫째 줄에 수빈이가 동생을 찾는 가장 빠른 시간을 출력한다.

둘째 줄에는 가장 빠른 시간으로 수빈이가 동생을 찾는 방법의 수를 출력한다.

URL

https://www.acmicpc.net/problem/12851

Remark

The problem asks us not just to find the shortest path, but to count the number of optimal paths to the target. A naive Breadth First Search(BFS) that explores every valid sequence of moves independently results in a TLE error due to exponential branching.

My initial approach was to aggressively prune the search space: if a trajectory reaches a previously visited node sub-optimally, it terminates. While this prevents infinite loops and gets the job done, it still suffers from queue duplication. If multiple optimal paths reach the same node at the exact same time, the node is pushed into the queue multiple times.

The Optimal Approach: To eliminate redundant processing, we can maintain a WAYS array alongside the STEPS array. This array explicitly tracks the number of optimal paths to each position. When we discover an alternative path that reaches a node in the exact same number of steps, we simply accumulate the ways in the WAYS array without pushing the node back into the queue.

Why WAYS Array Works

A natural question that arises when implementing this is: How can we be sure the WAYS array has collected ALL possible optimal paths before we pop that node from the queue to explore its children?

The answer lies in the nature of BFS. Because an unweighted BFS strictly processes nodes layer by layer, all nodes at distance d are guaranteed to be fully processed before any node at distance d+1 is popped.

Therefore, if a node is discovered at distance d+1, it gets pushed to the queue and waits. While it waits, the BFS finishes processing the rest of the nodes at level d. Any other nodes from level d that also connect to our waiting node will simply add their path counts to its WAYS value. By the time our node is finally popped, it has fully accumulated all converging paths from the previous depth.

An Early Exit

There is one more optimization we can make based on the problem's movement rules.

Notice the mechanics of the teleportation move (2×X): it always increases the coordinate (for X>0). Because teleporting only moves you forward, the only way to travel backwards on the number line is by walking (X−1).

This makes computation trivial in select cases: if the starting position N is greater than or equal to the target K (N≥K), we can completely bypass the BFS. We immediately know the shortest time is exactly N−K steps, and there is exactly 1 way to achieve it.

The final code is given in solve1().

Source Code

#include <iostream>
#include <vector>
#include <queue>

using namespace std;
const int INF = 1e9 + 7;

int N, K;
vector<int> STEPS(100000 + 1, INF);

int
out(int pos)
{
        return (pos < 0 || pos > 100000);
}

void
solve0(void)
{
        cin >> N >> K;
        queue<pair<int, int>> q;
        STEPS[N] = 0;
        int cnt = 0;

        q.push({0, N});
        while (!q.empty())
        {
                auto [dist, pos] = q.front(); q.pop();

                if (pos == K && dist == STEPS[pos]) {
                        if (STEPS[pos] == INF)
                        {
                                STEPS[pos] = dist;
                                cnt++;
                        }
                        else                            
                        {
                                cnt++;
                        }
                        continue;
                }                       

                int posinc = pos + 1;
                int posdec = pos - 1;
                int postel = 2*pos;

                for (int npos : {posinc, posdec, postel})
                {
                        if (out(npos)) continue;
                        if (STEPS[npos] < dist + 1) continue;

                        STEPS[npos] = dist + 1;
                        q.push({dist + 1, npos});
                }
        }

        cout << STEPS[K] << '\n' << cnt << '\n';
        return;
}

vector<int> WAYS(100000 + 1, 0);

void solve1()
{
        cin >> N >> K;

        if (N >= K)
        {
                cout << N - K << '\n' << 1 << '\n';
                return;
        }

        queue<int> q;
        STEPS[N] = 0;
        WAYS[N] = 1;
        q.push(N);

        while (!q.empty())
        {
                int pos = q.front();
                q.pop();

                if (STEPS[pos] > STEPS[K]) break;

                int next_positions[3] = {pos + 1, pos - 1, pos * 2};

                for (int npos : next_positions)
                {
                        if (npos < 0 || npos > 100000) continue;

                        if (STEPS[npos] > STEPS[pos] + 1)
                        {
                                STEPS[npos] = STEPS[pos] + 1;
                                WAYS[npos] = WAYS[pos]; 
                                q.push(npos); // Only push on the FIRST visit
                        } 
                        else if (STEPS[npos] == STEPS[pos] + 1) {
                                WAYS[npos] += WAYS[pos]; 
                        }
                }
        }

        cout << STEPS[K] << '\n' << WAYS[K] << '\n';
}

int
main(void)
{
        ios::sync_with_stdio(0); cin.tie(0);
        solve1();
        return 0;
}
