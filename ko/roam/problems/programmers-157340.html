programmers-157340 — 자동차 대여 기록에서 대여중 / 대여 가능 여부 구분하기

출처

프로그래머스 157340 — 자동차 대여 기록에서 대여중 / 대여 가능 여부 구분하기

문제

CAR_RENTAL_COMPANY_RENTAL_HISTORY 에서 자동차별 CAR_ID 와 2022-10-16의 대여 가능 여부인 AVAILABILITY 를 반환하는 문제입니다. 해당 날짜에 대여 중이면 대여중, 아니면 대여 가능 으로 표시합니다. 대여 종료일이 2022-10-16인 경우도 대여 중으로 봅니다. 결과는 CAR_ID 내림차순으로 정렬합니다.

테이블 구조

열 자료형 NULL 허용 의미
HISTORYID INTEGER 아니요 대여 기록 ID
CARID INTEGER 아니요 자동차 ID
STARTDATE DATE 아니요 대여 시작일
ENDDATE DATE 아니요 대여 종료일

입력 예시

CAR_RENTAL_COMPANY_RENTAL_HISTORY:

HISTORYID CARID STARTDATE ENDDATE
1 4 2022-09-27 2022-09-27
2 3 2022-10-03 2022-10-04
3 2 2022-10-05 2022-10-05
4 1 2022-10-11 2022-10-16
5 3 2022-10-13 2022-10-15
6 2 2022-10-15 2022-10-17

예상 출력

CARID AVAILABILITY
4 대여 가능
3 대여 가능
2 대여중
1 대여중

풀이

SELECT CAR_ID,
    CASE
        WHEN MAX(CASE WHEN START_DATE <= '2022-10-16' AND '2022-10-16' <= END_DATE THEN 1 ELSE 0 END) = 1
        THEN '대여중'
        ELSE '대여 가능'
    END AVAILABILITY
FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
GROUP BY CAR_ID
ORDER BY CAR_ID DESC

접근 방법

CAR_ID 로 그룹을 묶어 자동차별 대여 기록을 모두 살펴봅니다. 각 기록에서 2022-10-16이 시작일과 종료일을 포함한 대여 기간 안에 있는지 확인합니다. 조건을 만족하는 기록이 하나라도 있으면 대여중, 없으면 대여 가능 으로 표시합니다.

아래 쿼리는 서브쿼리로 해당 날짜에 대여 중인 자동차 ID를 구한 뒤, IN 으로 각 자동차가 그 집합에 속하는지 확인하는 방법입니다. 

SELECT 
    CAR_ID,
    CASE 
        WHEN CAR_ID IN (
            SELECT CAR_ID
            FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
            WHERE '2022-10-16' BETWEEN START_DATE AND END_DATE
        ) THEN '대여중'
        ELSE '대여 가능'
    END AS AVAILABILITY
FROM 
    CAR_RENTAL_COMPANY_RENTAL_HISTORY
GROUP BY 
    CAR_ID
ORDER BY 
    CAR_ID DESC;

정리

다른 문제에도 활용할 수 있는 핵심은 조건부 집계입니다. 각 행이 조건을 만족하는지 0 또는 1로 나타낸 뒤, 이 값을 집계해 그룹별로 하나의 답을 구합니다. MAX 는 값이 하나라도 1이면 1을 반환합니다. 자동차 2의 두 기록에서는 각각 0과 1이 나오므로 대여 중으로 표시합니다.

이는 여러 행에 걸쳐 OR 연산을 하는 셈입니다. 일반적인 OR 는 명시적으로 작성한 표현식을 결합하고, 집계 함수는 그룹에 속한 행들의 값을 모아 계산합니다. CASE WHEN condition THEN value ELSE other_value END 는 조건에 따라 0 또는 1을 만들거나 최종 표시 문구를 선택합니다.

PostgreSQL에서 같은 조건 표현하기

PostgreSQL에서는 BOOL_OR 로 그룹 안에 조건을 만족하는 행이 있는지 직접 표현할 수 있습니다. 이 문제의 두 날짜 열에는 NULL이 없으므로 모든 대여 기록에서 조건식은 참이나 거짓을 반환합니다. 바깥쪽 CASE 에서는 이 불리언 집계 결과를 바로 사용할 수 있습니다. 

CASE
    WHEN BOOL_OR(DATE '2022-10-16' BETWEEN START_DATE AND END_DATE)
    THEN '대여중'
    ELSE '대여 가능'
END AS AVAILABILITY

이 표현식은 앞서 CAR_ID 로 그룹을 묶은 SELECT 에 넣습니다. MySQL은 BOOL_OR 를 제공하지 않지만, 여기서는 기존의 MAX(CASE ... THEN 1 ELSE 0 END) = 1 로 같은 조건을 표현할 수 있습니다. MySQL에서는 비교 결과가 0 또는 1이므로 MAX(condition) 도 사용할 수 있습니다.
