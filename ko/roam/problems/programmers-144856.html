Programmers 144856 — 저자 별 카테고리 별 매출액 집계하기

문제

2022년 1월 도서 매출액을 저자별, 카테고리별로 계산하는 문제입니다. 매출액은 판매량에 가격을 곱해 구합니다. 예상 결과와 같이 AUTHOR_ID, AUTHOR_NAME, CATEGORY, TOTAL_SALES 를 반환합니다. 저자 ID를 기준으로 오름차순 정렬하고, 같은 저자의 결과는 카테고리를 기준으로 내림차순 정렬합니다.

테이블 구조

모든 열은 NULL을 허용하지 않습니다.

BOOK

열 타입 의미
BOOKID INTEGER 도서 ID
CATEGORY VARCHAR(N) 카테고리
AUTHORID INTEGER 저자 ID
PRICE INTEGER 가격(원)
PUBLISHEDDATE DATE 출판일

카테고리는 경제, 인문, 소설, 생활, 기술입니다.

AUTHOR

열 타입 의미
AUTHORID INTEGER 저자 ID
AUTHORNAME VARCHAR(N) 저자 이름

BOOKSALES

열 타입 의미
BOOKID INTEGER 도서 ID
SALESDATE DATE 판매일
SALES INTEGER 판매량

입력 예시

BOOK

BOOKID CATEGORY AUTHORID PRICE PUBLISHEDDATE
1 인문 1 10000 2020-01-01
2 경제 1 9000 2021-02-05
3 경제 2 9000 2021-03-11

AUTHOR

AUTHORID AUTHORNAME
1 홍길동
2 김영호

BOOKSALES

BOOKID SALESDATE SALES
1 2022-01-01 2
2 2022-01-02 3
1 2022-01-05 1
2 2022-01-20 5
2 2022-01-21 6
3 2022-01-22 2
2 2022-02-11 3

예상 결과

AUTHORID AUTHORNAME CATEGORY TOTALSALES
1 홍길동 인문 30000
1 홍길동 경제 126000
2 김영호 경제 18000

풀이

-- 코드를 입력하세요
SELECT 
        B.AUTHOR_ID,
    A.AUTHOR_NAME,
    B.CATEGORY,
    SUM(S.SALES_COUNT * B.PRICE) AS SALES
FROM
    BOOK B
JOIN
    AUTHOR A ON B.AUTHOR_ID = A.AUTHOR_ID
JOIN (
    SELECT 
        BOOK_ID, SUM(SALES) SALES_COUNT
    FROM 
        BOOK_SALES
    WHERE 
        SALES_DATE LIKE '2022-01%'
    GROUP BY 
        BOOK_ID    
) S ON B.BOOK_ID = S.BOOK_ID
GROUP BY
    B.AUTHOR_ID,
    A.AUTHOR_NAME,
    B.CATEGORY
ORDER BY
A.AUTHOR_ID ASC,
B.CATEGORY DESC

접근 방법

서브쿼리에서 1월 판매 내역만 골라 도서별 판매량을 합산합니다. 바깥 쿼리에서는 이 결과를 도서 가격 및 저자 정보와 조인한 뒤, 저자별, 카테고리별 매출액을 합산합니다.

기억할 점

SQL LIKE 패턴에서 % 는 빈 문자열을 포함해 길이에 상관없이 문자열과 일치하고, _ 는 정확히 한 문자와 일치합니다. '2022-01%' 는 “2022-01로 시작하는 값”을 뜻합니다. 이 기호들은 SQL 와일드카드이며 정규 표현식 문법이 아닙니다.

문자열의 어느 부분을 찾을지에 따라 와일드카드 위치를 정합니다. 'place%' 는 시작 부분, '%place' 는 끝부분, '%place%' 는 문자열 안의 어느 위치에서든 해당 문자열을 찾습니다. 문법이 헷갈리면 어느 부분이 고정되어 있고 어느 부분이 달라질 수 있는지 생각해 봅니다.
