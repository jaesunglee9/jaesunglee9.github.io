programmers-299310 — 연도별 대장균 크기의 편차 구하기

출처

프로그래머스 299310 — 연도별 대장균 크기의 편차 구하기

문제

링크된 문제를 요약하면 다음과 같습니다. ECOLI_DATA 의 각 대장균에 대해 분화 연도는 YEAR 로, 해당 연도의 최대 개체 크기에서 자신의 크기를 뺀 값은 YEAR_DEV 로, 개체 ID는 ID 로 반환합니다. YEAR 를 기준으로 오름차순 정렬하고, 같은 연도에서는 YEAR_DEV 를 기준으로 오름차순 정렬합니다.

테이블 구조

열 자료형 NULL 허용 의미
ID INTEGER 아니요 개체 ID
PARENTID INTEGER 예 부모 ID
SIZEOFCOLONY INTEGER 아니요 개체 크기
DIFFERENTIATIONDATE DATE 아니요 분화 날짜
GENOTYPE INTEGER 아니요 유전자형

최초 개체의 부모 ID는 NULL 입니다.

입력 예시

ECOLI_DATA:

ID PARENTID SIZEOFCOLONY DIFFERENTIATIONDATE GENOTYPE
1 NULL 10 2019/01/01 5
2 NULL 2 2019/01/01 3
3 1 100 2020/01/01 4
4 2 10 2020/01/01 4
5 2 17 2020/01/01 6
6 4 101 2021/01/01 22

기대 출력

YEAR YEARDEV ID
2019 0 1
2019 8 2
2020 0 3
2020 83 5
2020 90 4
2021 0 6

풀이

SELECT YEAR(DIFFERENTIATION_DATE) AS YEAR,
    (MAX(SIZE_OF_COLONY) OVER (PARTITION BY YEAR(DIFFERENTIATION_DATE)) - SIZE_OF_COLONY) AS YEAR_DEV,
    ID
FROM ECOLI_DATA 
ORDER BY YEAR ASC, YEAR_DEV ASC

접근

GROUP BY와 PARTITION BY의 차이를 몰랐고, 이렇게 나눈 파티션에 MAX를 적용하면 무엇을 구하는지도 몰랐습니다.

정리

결과의 각 행에 개별 값과 그 행이 속한 그룹의 통계값이 함께 필요할 때는 윈도 집계 함수를 사용합니다. 이 문제에서는 각 대장균의 ID와 크기를 유지하면서 같은 연도의 최대 개체 크기를 각 행에서 구합니다. 이 값에서 각 개체의 크기를 빼면 행마다 편차를 계산할 수 있습니다.

GROUP BY는 그룹마다 한 행을 만듭니다. 한 연도에 크기가 서로 다른 개체가 여러 개라면, 그룹화하지 않은 크기 열에서 어떤 값을 선택할지 모호합니다. 집계 함수를 쓰면 요약값을 구하고, 크기를 그룹화 기준에 추가하면 그룹을 나누는 기준 자체가 달라집니다.
