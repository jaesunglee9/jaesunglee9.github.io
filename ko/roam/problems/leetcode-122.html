LeetCode 122 — 주식 매매로 최대 이익 구하기 II

문제

prices[i] 는 i 번째 날의 주가입니다. 총이익이 최대가 되도록 매수와 매도 시점을 정하고, 얻을 수 있는 최대 이익을 반환합니다. 여러 번 거래하거나 같은 날 팔고 다시 살 수 있지만, 어느 시점에도 한 주까지만 보유할 수 있습니다.

제약 조건

  • 1 < prices.length <= 3 * 104=
  • 0 < prices[i] <= 104=

예시

prices 출력
[7,1,5,3,6,4] 7
[1,2,3,4,5] 4
[7,6,4,3,1] 0

첫 번째 예시에서는 1에 사서 5에 팔면 4, 3에 사서 6에 팔면 추가로 3의 이익을 얻습니다. 두 번째 예시에서는 1에 사서 5에 팔면 이익이 4입니다. 세 번째 예시에서는 거래하지 않으면 이익이 0입니다.

풀이

#include <vector>

using namespace std;

class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int profit = 0;

        for (int i = 1; i < prices.size(); ++i) {
            if (prices[i] > prices[i - 1]) {
                profit += (prices[i] - prices[i - 1]);
            }
        }

        return profit;
    }
};

접근 과정

class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int profit = 0;
        int s = 0;
        while (s < prices.size()) {
            // check for ascending range
            int e = s + 1;
            while (e < prices.size() && prices[e] >= prices[e-1]) {
                e++;
            }
            // if range is 1 (is descending) s should be incremened
            if (e - s == 1) {
                s++;
            }
            // else (there exists nonzero range) add to profit the possible thing, set s to e + 1
            else {
                profit += (prices[e-1] - prices[s]);
                s = e;
            }
        }

        return profit;
    }
};

돌아보기

가격이 내려가지 않는 구간에서는 양 끝의 가격 차이와 하루하루의 가격 차이를 모두 더한 값이 같습니다. 즉, \(p_b-p_a=\sum_{i=a+1}^{b}(p_i-p_{i-1})\) 입니다. 가격이 1, 3, 5라면 1에 사서 5에 팔 때의 이익은 4이고, 인접한 날의 상승분을 더해도 2 + 2 = 4입니다. 인접한 날의 가격 변화만 더해도 원하는 합계를 구할 수 있으므로 구간의 양 끝을 따로 찾을 필요가 없습니다.

이 탐욕적 풀이는 거래 수수료와 매도 후 재매수 대기 기간이 없고, 거래 횟수에도 제한이 없다는 조건에 의존합니다. 이런 제약이 생기면 어느 날의 결정이 다른 날의 결정에 영향을 줄 수 있습니다. 따라서 같은 방식으로 단순화해도 되는지 근거를 다시 따져야 합니다.
