Baekjoon 16953 — A → B

Source

https://www.acmicpc.net/problem/16953

Problem

정수 A에서 시작해 다음 두 연산 중 하나를 반복하여 B를 만든다.

  • 현재 값에 2를 곱한다.
  • 현재 값의 오른쪽에 숫자 1을 붙인다.

B를 만들기 위한 최소 연산 횟수에 1을 더한 값을 구한다.

입력

A와 B가 주어진다. 두 수는 1 이상 109 이하이며 A는 B보다 작다.

출력

B를 만들 수 있으면 최소 연산 횟수에 1을 더한 값을 출력하고, 만들 수 없으면 -1을 출력한다.

Solution

#include <iostream>
#include <queue>

using namespace std;
using ll = long long;

void
sol0(ll a, ll b)
{
        priority_queue<pair<int, ll>, vector<pair<int, ll>>, greater<pair<int, ll>>> pq;

        pq.push({0, a});

        while (!pq.empty())
        {
                auto [nop, num] = pq.top(); pq.pop();

                if (num == b)
                {
                        cout << nop + 1 << '\n';
                        return;
                }
                if (num > b)
                {
                        continue;
                }

                pq.push({nop + 1, num * 2});
                pq.push({nop + 1, num * 10 + 1});
        }

        cout << "-1\n";
        return;
}               


int
main(void)
{
        ll a, b;

        cin >> a >> b;
        sol0(a, b);
        return 0;
}
