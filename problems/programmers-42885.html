programmers-42885 — Lifeboats (구명보트)

Source

Programmers 42885 — 구명보트

Problem

This is an English summary of the original problem. See the source link for the full statement.

Rescue everyone from an island using lifeboats. Each boat carries at most two people, and their combined weight must not exceed limit. Given the individual weights in people, return the minimum number of boats needed to carry everyone.

Interface and constraints

  • C++ interface: int solution(vector<int> people, int limit)
  • There are between 1 and 50,000 people.
  • Each person weighs between 40 and 240 kg, inclusive.
  • limit is between 40 and 240 kg, inclusive.
  • The statement guarantees that limit is greater than the heaviest person's weight, so everyone can be rescued.

Examples

people limit return
[70, 50, 80, 50] 100 3
[70, 80, 50] 100 3

Solution

#include <string>
#include <vector>
#include <algorithm>

using namespace std;

int solution(vector<int> people, int limit) {
    int answer = 0; 
    sort(people.begin(), people.end());
    int i = 0;
    int j = people.size() - 1;
    while (i <= j)
    {
        int tmp =  limit - people[j];
        if (tmp < people[i]) {
            j--;
        }
        else {
            j--;
            i++;
        }
        answer++;

    }

    return answer;
}

Approach

Why does greedy work here? Note that boat can carry at most two. Now. Sort the people by weight. Take the heaviest and lightes person's weight. There can be two cases: 1. the boat can accomdate the heaviest and the lightest person, in which case it is optimal, or 2. weight of them both combined exceeds capacity. In this case, there is no way the heavier person can cross with company, since we used the lightest person's weight. Thus, we can cross him now, without worry(that it might be suboptimal) .

Note that the cleaned up code is: 

#include <string>
#include <vector>
#include <algorithm>

using namespace std;

int solution(vector<int> people, int limit) {
    int answer = 0; 
    sort(people.begin(), people.end());
    int i = 0;
    int j = people.size() - 1;
    while (i <= j) {
        if (limit >= people[i] + people[j]) {
            i++;
        }
        j--;
        answer++;   
    }     
    return answer;
}

This solution uses greedy pairing: each iteration chooses a boat's occupants from the remaining people. The sorted array and its two endpoint indices represent those remaining people.

Remarks

The pattern worth remembering here is two pointers moving inward. A useful pattern is: can the unprocessed elements stay in one range, with each decision handling or ruling out one or both endpoints?
