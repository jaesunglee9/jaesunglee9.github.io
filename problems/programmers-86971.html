Programmers 86971 — 전력망을 둘로 나누기

Source

https://school.programmers.co.kr/learn/courses/30/lessons/86971

Problem

n개의 송전탑이 전선을 통해 하나의 트리 형태로 연결되어 있습니다. 당신은 이 전선들 중 하나를 끊어서 현재의 전력망 네트워크를 2개로 분할하려고 합니다. 이때, 두 전력망이 갖게 되는 송전탑의 개수를 최대한 비슷하게 맞추고자 합니다.

송전탑의 개수 n, 그리고 전선 정보 wires가 매개변수로 주어집니다. 전선들 중 하나를 끊어서 송전탑 개수가 가능한 비슷하도록 두 전력망으로 나누었을 때, 두 전력망이 가지고 있는 송전탑 개수의 차이(절대값)를 return 하도록 solution 함수를 완성해주세요.

제한사항

  • n은 2 이상 100 이하인 자연수입니다.
  • wires는 길이가 n-1인 정수형 2차원 배열입니다.
    • wires의 각 원소는 [v1, v2] 2개의 자연수로 이루어져 있으며, 이는 전력망의 v1번 송전탑과 v2번 송전탑이 전선으로 연결되어 있다는 것을 의미합니다.
    • 1 ≤ v1 < v2 ≤ n 입니다.
    • 전력망 네트워크가 하나의 트리 형태가 아닌 경우는 입력으로 주어지지 않습니다.

Solution

#include <string>
#include <vector>

using namespace std;
vector<vector<int>> G;
vector<int> P;

int N;
int mn_diff = 9999999;

int dfs(int u) {
    if (G[u].size() == 1 && G[u][0] == P[u]) {
        return 1;
    }

    int tree_sum = 1;
    for (auto v : G[u]) {
        if (v == P[u]) continue;
        P[v] = u;

        int subtree_sum = dfs(v);
        mn_diff = min(mn_diff, abs(N - 2 * subtree_sum));
        tree_sum += subtree_sum;
    }

    return tree_sum;
}

int solution(int n, vector<vector<int>> wires) {
    int answer = -1;
    N = n;
    G.resize(n+1);
    P.resize(n+1);
    for (auto e : wires) {
        G[e[0]].push_back(e[1]);
        G[e[1]].push_back(e[0]);
    }

    dfs(1);

    return mn_diff;
}

Approach

The solution roots the tree at tower 1 and uses a postorder DFS. dfs(u) returns the number of towers in u's subtree. After a child returns a subtree size s, removing the edge to that child would split the network into components of sizes s and N-s, whose difference is abs(N - 2s). Taking the minimum over all parent-child edges therefore evaluates every possible wire removal in one traversal.

This is Depth First Search with postorder subtree-size aggregation.

Implementation note

Browsing other people's code, I found some improvements to be made over original code, which is as follows: 

#include <vector>
#include <algorithm>
#include <cmath>

using namespace std;

int solution(int n, vector<vector<int>> wires) {
    vector<vector<int>> adj(n + 1);
    for (const auto& w : wires) {
        adj[w[0]].push_back(w[1]);
        adj[w[1]].push_back(w[0]);
    }

    int min_diff = n;

    // Single-pass DFS: returns subtree size while minimizing difference
    auto dfs = [&](auto& self, int u, int p) -> int {
        int sub_size = 1;
        for (int v : adj[u]) {
            if (v == p) continue;
            int child_size = self(self, v, u);
            min_diff = min(min_diff, abs(n - 2 * child_size));
            sub_size += child_size;
        }
        return sub_size;
    };

    dfs(dfs, 1, 0);

    return min_diff;
}

This is a better, cleaner implementation. Note the use of recursive lambdas, and sending parent with u.
